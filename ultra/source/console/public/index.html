首次使用如何获取 token？

token 已随机生成并保存于控制台数据目录的 key 文件。管理员可在宿主或容器终端运行：

node /opt/sm75-workbench/console/auth-cli.mjs show

升级会保留已有 token；登录 token 与模型 API Key 分开管理。

上下文与 GPU KV

上下文与缓存说明

填写 GPU KV 后使用每卡固定预算，优先于显存利用比例。CPU 缓存用于卸载和复用，不能与 GPU 容量相加计算单个活动请求的上下文。

1M 为 1,048,576 tokens，YaRN 倍率按模型原生位置长度计算。更换模型后需重新配置；扩展后的质量与容量仍需按模型验证。

CPU KV 与分层缓存

使用引擎原生 CPU KV；容量为所有 TP 卡的合计。

磁盘与服务设置
LMCache 使用说明

LMCache 0.5.5 提供 CPU 与磁盘分层缓存。缓存块大小须为运行日志中的块大小或其整数倍，更换模型或 TP 后重新核对。

磁盘目录使用 Linux 绝对路径。“剩余空间”只做启动检查，用量上限由卷配额控制。启动时会检查依赖和缓存服务。

当前支持 Ultra 单容器和本机运行；需使用 P-State，暂不支持 DFlash / MTP。选择此方案会替代原生 CPU KV，自定义连接器与草稿配置需手动处理。
