# vLLM-SM75 v0.1.3 — 自动休眠适配

## 更新简要

- 新增空闲自动休眠与透明唤醒，`docker/run.sh` 默认空闲 30 分钟后进入 `exit` 深度休眠。
- 修正空闲计时起点，使计时从请求完成并进入 idle 后开始。
- 统一构建与启动入口为 `docker/build.sh` 和 `docker/run.sh`。

## 功能要点

- 继承 v0.1.2 的 FlashQLA-SM75 GDN prefill、Triton decode、FlashInfer 0.6.18、Marlin FP8、FP8 KV、MTP5 和 DFlash2 适配。
- 支持 ModelScope、模型缓存与 vLLM/FlashInfer 编译缓存持久化。
- 统一镜像通过启动参数选择普通推理、MTP5 或 DFlash2。
- 自动休眠支持 CPU、reload 和 exit；exit 模式释放引擎进程、CUDA context、worker 和显存，下一请求透明冷启动。

## 已完成的本地验证

镜像内 selector/auto-sleep 测试 44 项全部通过。基于 FP8 MTP5 的 exit 模式实测：自动卸载后四卡均进入 P8、每卡显存 3 MiB，平均功耗约 10–15 W；透明唤醒和并发请求恢复通过。

完整条件与原始数据见 v0.1.3 验证记录。
