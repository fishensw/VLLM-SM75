## 更新说明

本次新增运行中投机解码开关，默认采用 P-State 常驻省电，并推出 ultra 版本。ultra 在标准版推理服务上增加 Web 管理、随机 token 登录、快速会话和 DSH 工作台，以及统一实时页头、导航和品牌资源。

## 当前候选与生产

后续已完成[模型推荐与服务默认分离](../validation/2026-09-18-model-recommendations.md)，独立 UI 候选镜像 58 项测试及 HTTP 验证通过。该候选基于下述完整镜像，尚未部署；下述 22 项 GPU 结果仍对应原完整构建。

两版最终候选均来自 `cd3eef6`，各 43 个运行时文件与源码匹配；ultra 78 个界面资源匹配。引擎测试各 48 项，控制台测试 53 项，GPU 长上下文验收标准版 6 项、ultra 16 项全部通过。覆盖 262144 总上下文及连续 512 输出，原基线 token 哈希一致。

本轮修复了监控开关误触发编译缓存失效的问题，并重新完整构建和验收。首次 262K 请求仍有 2 次 KV 抢占，独立冷编译一致性未作普遍保证；结果范围见验收记录。

生产继续使用原 RC7 镜像及其后续静态修复，数据、会话和回退容器保留。本轮候选尚未切换到生产。旧 RC 构建及部署记录保留作历史证据，不作为最新安装入口。

## 发布附件

standard/ultra 共用一个源码包，版本统一来自 `docker/VERSION`，使用 `docker/build.sh`、`docker/run.sh`；不复制版本化配方或运行脚本。

发布附件包含源码包及 SHA256、版本清单、更新说明和验收记录；两份完整 OCI 镜像及校验和另行保留。源码包来自以既有公开基线整理的本地审核分支，不包含内部中间提交历史、凭据、会话、模型、缓存或私有日志，保留第三方许可。

源码和资料发布已获用户授权。Release 正文使用版本固定的 GitHub 链接，附件附带 SHA256；公开 Docker 镜像发布与生产切换另行执行。
