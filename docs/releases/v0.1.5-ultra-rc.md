## 已实现

1. 导入标准版构建入口及 ultra 源码、插件、覆盖层；认证抽为模块，将主要维护文件格式化为可审阅代码。
2. 首次随机 token、旧凭据保留、服务端会话摘要与绝对过期、重启恢复、退出/轮换撤销连接、登录限速、同源检查和可信代理 Secure Cookie。
3. 去掉构建号强制 reload、登录后强制 DSH 跳转和服务端根路由重定向。登录状态与模型/DSH 服务故障分离，异步登录结果通过代际检查避免旧请求覆盖新状态。
4. 配置页错误闭合标签修复、统一导航、历史路由、未保存配置对话框、隐藏面板遥测暂停、会话/测试/编辑草稿保留；模型库选择配置不立即启动推理。
5. 旧 `idleMinutes` 转换恢复；模型启动失败清理电源 supervisor；停止其他配置不影响活动模型；日志增量读取限制为 8 MiB；文件下载路径核验真实路径，阻止软链越界。
6. vLLM 形态与闪电的矢量组合，透明/底板/单色、16/32/48 ICO、32/64/180/192/512 PNG 与 maskable；登录、导航、DSH 与 PWA 使用同一资产入口。
7. ultra 完整构建改用固定 Node digest 与 npm 锁文件，不再依赖宿主二进制和私有 node_modules 镜像。保留增量候选构建作诊断用途。
