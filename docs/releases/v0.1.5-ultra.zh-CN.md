# vLLM-SM75 v0.1.5-ultra — Web 管理、快速会话与工作台

在 v0.1.5 相同推理基座上集成 Web 控制台和 DSH 工作台，完善登录、导航、实时状态及持久化。源码随 [v0.1.5](https://github.com/fishensw/VLLM-SM75/releases/tag/v0.1.5) 发布；Docker 镜像需自行构建，尚未提供公开镜像。

## ultra 专属功能与更新

- **管理与会话**：集成模型库、运行配置、快速会话、DSH 工作台和性能监控；复用标准版 SM75 推理优化。
- **首次登录**：首次启动生成随机 Web token，支持局域网访问；Web 会话通过 HttpOnly、SameSite=Strict Cookie 维护。新安装区分 Web token 与引擎 API key，原安装保留已有凭据。
- **登录跳转修复**：确认会话时不闪现登录表单；管理导航支持深链、刷新和浏览器前进/后退；引擎或工作台暂时不可用不直接判定为退出登录。
- **统一状态页头**：快速会话和工作台共用组件、位置一致；固定布局先显示，指标异步刷新。合并运行/P-State 状态与 GPU 温度、功耗、核心利用率、显存占用、P、D、上下文 KV 和命中指标；性能监控页不重复显示该指标条。
- **模型生成参数**：显示服务默认数值与输出预算，提供 Qwen3.8-27B 思考/非思考推荐参数，支持存在惩罚、自定义参数及恢复服务默认。

### 兼容性修复

修复配置离开与草稿保留、单容器并发启动互斥、进程启动失败后的清理；DSH 工具固定 UID/GID 1000，降权失败直接报错。首次安装编译缓存默认目录修正为持久化的 `/data/cache`，已保存的缓存路径保持原值。

账户登录与客户端 CIDR 白名单尚未实现。`SM75_TRUSTED_PROXIES` 是反向代理信任列表，不能当作客户端网段白名单。

## 适合谁使用

需要浏览器模型管理、快速会话和 DSH 工作台时选择 ultra；仅提供推理 API 或已使用其他客户端时选择标准版。ultra 包含标准版的投机开关和默认 P-State，下面列出的是 ultra 专属功能。完整对照见 [版本选择](v0.1.5.zh-CN.md#版本选择)。

## 推荐使用

从仓库根目录使用与标准版相同的构建/运行入口：

```bash
bash docker/build.sh
EDITION=ultra bash docker/build.sh
ULTRA_DATA_ROOT=/path/to/ultra MODEL_ROOT=/path/to/models \
  EDITION=ultra bash docker/run.sh
docker exec vllm-sm75-ultra node /opt/sm75-workbench/console/auth-cli.mjs show
```

上例用于首次安装，路径需替换为实际绝对路径。浏览器访问 `http://<局域网地址>:1615`，使用管理终端读取的 token 登录，再登记模型与配置。默认只启动管理服务；推理端口为 8000。已有安装必须保留原挂载，不可用空目录替换原配置。

默认常驻 P-State（空闲 P8 / 负载回 16），自动休眠 exit 保留为可选配置。P-State 需要 `PSTATE_NVAPI_LIB` 指向宿主驱动库；未挂载时选择 sleep。登录、凭据恢复、会话期限、持久化与 DSH 权限见 [ultra 使用指南](../../ultra/README.md)。

### 首次登录：自动密钥在哪里、怎么看

首次启动会自动生成 **Web 登录 token**，无需自行填写或预设。容器内保存在 `/data/key`；使用上面的统一运行脚本时，宿主机对应 `<ULTRA_DATA_ROOT>/console/key`，例如 `/path/to/ultra/console/key`。重启或升级保留该数据目录，就会继续使用原 token。

在 **Docker 宿主机终端**执行以下命令，输出的一整行就是登录 token：

```bash
docker exec vllm-sm75-ultra node /opt/sm75-workbench/console/auth-cli.mjs show
```

若设置过 `CONTAINER_NAME`，将 `vllm-sm75-ultra` 换成实际容器名；可用 `docker ps --format '{{.Names}}'` 查看。Unraid 可在 Docker 页面点击 ultra 容器图标 → **Console / 控制台**，进入容器后执行：

```bash
node /opt/sm75-workbench/console/auth-cli.mjs show
```

浏览器打开 `http://<宿主机局域网IP>:1615`（独立容器 IP 部署则使用容器 IP；自定义端口使用实际端口），将输出的 token 粘贴到登录框即可。此 token 用于 Web 管理登录，**不是模型推理 API key**。查看命令不会轮换已有 token；不要为查看密钥执行 `reset`。

## 更新与发布

升级前对管理数据、会话、模型配置、DSH home/workspace 做一致性备份，保存原镜像 ID、启动参数和挂载。旧 root DSH 数据按使用指南复制到独立升级目录，调整副本所有权为 1000:1000，保留原目录用于回退。不要将 Docker socket 或 privileged 权限授予工作台。

先验证独立候选，切换时仅停止相关模型容器，不停止 Docker 服务。回退使用原镜像与匹配的数据目录，并保留升级后新增会话。完整流程见 [升级及回退](../../ultra/README.md)。

标准版和 ultra 共用版本源与发布资料，不按 RC 编号新增一套运行脚本。发布资料与验证范围见 [当前发布状态](v0.1.5.md)；RC 历史仅供排查。
