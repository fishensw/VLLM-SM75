## 测试配置

README 的本轮实测使用以下参数，均为单请求、1024 输出 tokens；每个输入长度测量一次。

| 配置 | seq | batch tokens | utilization | GPU KV / 每卡 | max-model-len |
|---|---:|---:|---:|---|---|
| FP8 普通 / MTP5 | 4 | 8192 | 0.87 | 自动 | auto |
| FP8 DFlash2 | 4 | 8192 | 0.92 | 3.0625 GiB | 262144 |
| AWQ 普通 / MTP5 | 8 | 16384 | 0.87 | 自动 | auto |
| AWQ DFlash2 | 8 | 16384 | 0.87 | 4 GiB | auto |

使用 FP8 e4m3 KV、8 GiB CPU KV offload；MTP5 capture `[6]`，DFlash draft7 capture `[8]`，draft 为 `incoai/Qwen3.8-27B-DFlash2`。

请求采用流式 chat API：重复英文测量说明段落后要求生成 Python benchmark 工具，输入为 1173 / 36885 tokens（含聊天模板）。temperature=0、关闭 thinking、ignore_eos=true、独立 cache_salt，cached_tokens 均为 0。

decode 按 `(completion_tokens - 1) / (最后文本事件时间 - 首个文本事件时间)` 计算。历史三轮性能结果见[发布说明](../releases/v0.1.2.zh-CN.md)。
