## API adaptations and checks

- v0.30 removed Marlin `g_idx`, permutation and `is_k_full` arguments, plus the fourth weight-tuple element and required `has_g_idx` config field. Firefly custom-op, fake signature, caller and decode path now follow the v0.30 API. Legacy external configs with explicit act-order stay gated off.
- Reviewed old/new gptq_marlin_repack.cu: upstream removes the act-order branch; the non-permuted INT4 layout used by Firefly is preserved. Final native Firefly CUDA verification passed: decode relative RMSE 0.042%–0.046%, prefill 0.850%–0.860%.
- [Upstream PR #53376](https://github.com/vllm-project/vllm/pull/53376) backported to scaled_mm/cutlass.py. Native FP8 CUTLASS now checks the compiled CUDA capability probe. Unsupported SM75/80/86 falls through to Marlin; INT8 CUTLASS is unchanged.
- FlashInfer 0.6.18 exports get_seq_lens and its prefill/decode plan signatures accept seq_lens, as required by the rebased backend. The new upstream PCIe IPC backend is opt-in and safely detects absent FlashInfer APIs. TP4 FlashInfer/FA2 and FULL_AND_PIECEWISE graph execution passed in the final service tests.
- Env injection still matches the upstream environment_variables/compile_factors API. Marlin workspace allocator still accepts existing= for address-preserving reload.
- Renderer initialization and original cache block-size snapshot coexist in MPClient. launch_core_engines retains its call signature. SM75 num_spec_tokens scheduler property still matches upstream AsyncScheduler access.
- Monitor HTML can be disabled while retaining spec_decode GET/POST for Ultra. POST authorization and not-configured 409 behavior are unchanged.

## Final GPU integration

- New `scaled_mm/humming.py` overlay excludes SM75 FP16 input/output with tensor/channel FP8 scales. The CT W8A16 adapter expands tensor scales after kernel selection, so the gate covers both forms and does not depend on stale activation metadata.
- Real checkpoint input after its own RMSNorm produced 3/23 nonfinite values under Humming (batch 1/7), with zero in the dense reference. Marlin produced zero nonfinite values and relative RMSE 0.290%/0.285%. After the gate, auto selected Marlin and passed the same assertions.
- Final combined GPU run: 65 passed (34 FP8 numerical cases, 27 Humming scope/runtime-selector cases, 4 native Firefly cases). Earlier failing diagnostic logs were preserved.
- A fixed internal `0.1.6-1` compile factor separates the changed kernel and packing choices from prior caches. Same-release idle/monitor changes still reuse cache; five cache tests passed on Linux.
- See [final validation](v0.1.6.md) for whole-model acceptance, observed long-output differences, environment boundaries and remaining build coverage.
