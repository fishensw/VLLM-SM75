## 指标契约

- GPU：可见 GPU 的最高温度；功耗：可见 GPU 合计 W。悬停可查看各卡；任一卡缺测则对应汇总不展示数值。
- Prefill / Decode：复用后台 5 秒采样的引擎全局吞吐，单位 tok/s；Prefill 使用本地实际计算输入 token 计数。
- 上下文 KV：引擎 GPU KV 缓存占用百分比，不代表当前会话 tokens / 模型最大上下文。
- Cache：最近最多 60 秒 prefix cache hits / queries 的增量比率；无查询、计数重置或采样中断显示 —。
- 引擎样本超过 15 秒或采样失败立即视为不可用；硬件单独判断有效期。前端请求失败清空数值。
- 快速会话跟随运行配置选择；单容器工作台跟随当前引擎，未运行时等待采样。
- 登录保护的 `/console-api/live-summary` 复用已有 Telemetry；硬件只做被动 NVML 查询，复用短期缓存与在途请求。页面隐藏时暂停查询，卸载时取消请求。
