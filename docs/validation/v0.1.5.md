# v0.1.5 / ultra 验证记录

与 v0.1.4 相同，本页作为发布说明对应的固定验证入口；逐次测试数据按日期保留。当前为候选版资料，不代表已正式发布。

## 测试配置

4× Tesla T10 16 GiB，27B FP8+DFlash2 TP4；draft7、seq4、batch8192、block32、FP8 e4m3 KV、每卡 KV 3288334336 bytes、CPU KV 8 GiB、capture `[8]`、最大长度 262144。此为已测生产配置，不等于脚本全部默认值。

性能输入 8192/32768 tokens，greedy、512 输出，每档独立预热一次再五次；每请求使用独立 cache salt。Prefill 为输入 tokens/TTFT，Decode 排除首 token 前等待。`ignore_eos=true` 用于固定输出长度，不是自然停止质量验证。

## 最终候选验收

后续[模型推荐与服务默认分离](2026-09-18-model-recommendations.md)已完成独立 UI 候选构建、58 项 Linux 测试和 HTTP 验证；未重跑下述 GPU 矩阵，未部署生产。

源码 `cd3eef6` 的标准版与 ultra 均完成独立完整构建，22 项 GPU 长上下文检查全部通过，原基线输入与输出 token 哈希一致；包含 262144 总上下文和连续 512 输出。本轮修复监控开关导致的编译缓存失效后重新构建，两版均通过实际镜像检查。生产已恢复，候选等待用户确认，未推广或发布。

## 既有镜像性能回归

以下表格对应此前的保留 v0.1.4、既有标准版及生产 ultra 镜像；本轮最终候选没有重做五次独立性能矩阵。

| 镜像 | 输入 | Prefill tok/s | Decode tok/s | TTFT 秒 |
|---|---:|---:|---:|---:|
| 保留 v0.1.4 | 8192 | 1268.73 | 63.65 | 6.457 |
| v0.1.5 | 8192 | 1267.09 | 63.60 | 6.465 |
| ultra | 8192 | 1271.23 | 63.43 | 6.444 |
| 保留 v0.1.4 | 32768 | 1203.47 | 60.11 | 27.228 |
| v0.1.5 | 32768 | 1202.19 | 60.10 | 27.257 |
| ultra | 32768 | 1203.56 | 59.95 | 27.226 |

表格为五次中位数。30 样本全部有效，零缓存命中、零抢占、检索通过，同输入输出 token 哈希一致；通过预设 5% 吞吐容忍线，最大中位数下降约 0.35%。不构成所有模式的性能保证。
